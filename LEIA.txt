Caminhada do exo para NVIDIA Jetson Nano, Ubuntu 18, CANable v2.

Valores padrao da caminhada: coxa 18 graus, joelho 45 graus e cinco passos
alternados. O torque nominal e 72/15 Nm; o pico de 120/25 Nm so pode ocorrer
por ate 0,25 s. Consulte os parametros no inicio de caminhada_torque_pleno.py.
O programa fala SLCAN direto na porta serial. Nao use slcand junto.

POSICAO INICIAL OBRIGATORIA: antes de iniciar qualquer controlador, coloque o
exo de pe, com as duas pernas retas, alinhadas entre si e a 90 graus em relacao
a caixa de suporte da bateria. Os programas adotam a leitura inicial dos
encoders como referencia; nao alinham o exo automaticamente.

No Jetson, dentro desta pasta:

  sudo apt-get update
  sudo apt-get install -y python3-pip
  pip3 install -r requirements.txt
  sudo usermod -a -G dialout $USER

Saia e entre de novo no usuario para o grupo dialout valer.
Ligue a CANable e confira o nome:

  ls /dev/ttyACM*

O padrao e /dev/ttyACM0. Se aparecer outro nome, passe na linha de comando.

Antes da caminhada, calibre os dois batentes de cada motor com o exo apoiado,
sem pessoa usando e sem outro programa conectado a CANable:

  python3 medir_batentes.py --checar
  python3 medir_batentes.py
  python3 ver_angulos_batente.py

Siga cada solicitacao e mova a articulacao devagar ate o batente mecanico,
sem forcar alem dele. Confirme a atualizacao de suporte_marcha.py somente se
todos os oito extremos estiverem corretos. Veja GUIA_DE_USO.md para a funcao
de cada script e o procedimento completo.

Para usar o desligamento por botoes com o usuario nvidia, revise e valide a
regra incluida antes de instalar:

  sudo visudo -cf exo-desliga.sudoers
  sudo install -o root -g root -m 0440 exo-desliga.sudoers /etc/sudoers.d/exo-desliga
  sudo visudo -cf /etc/sudoers.d/exo-desliga

A regra permite somente `systemctl poweroff` e `shutdown -h now`.

  python3 caminhada_torque_pleno.py
  python3 caminhada_torque_pleno.py /dev/ttyACM1

Os angulos, o ciclo, os passos e os torques ficam no topo de
caminhada_torque_pleno.py. O registro de cada ensaio sai em ensaios/.

Mantenha o exo apoiado. Nao rode este programa ao mesmo tempo que o
Windows estiver com a mesma CANable aberta.
